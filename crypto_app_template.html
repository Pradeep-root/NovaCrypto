🎨 How to Import This into Penpot
Step-by-step guide — from this HTML template to a Penpot design file with Material Design 3 components
1
Screenshot each phone frame in Chrome
Open this file in Chrome → press F12 → click the device icon (Ctrl+Shift+M) → set to 360 × 800. Right-click each .phone element in DevTools → "Capture node screenshot" → you get a clean 360×800 PNG per screen.
2
Create a Penpot file with 4 pages
Go to penpot.app → New Project → New File. Add 4 pages at the bottom: Markets, Coin Detail, Search, Portfolio. One screen per page keeps layers clean.
3
Set Android frame (360 × 800)
Press F (Frame tool) → drag a frame → in the right panel set W: 360, H: 800. In Penpot's frame preset dropdown select Android Small if available, or enter manually. Set background to #FFFBFE (MD3 background token).
4
Import screenshots as reference underlays
Drag each PNG into its Penpot page → place inside the 360×800 frame → lock the layer (Ctrl+L) → set opacity to 35–40%. Trace your MD3 components on top of this ghost layer.
5
Build MD3 components
Top App Bar: Rect H:64 fill #F7F2FA radius 0. Text font Roboto 22sp.
Cards: Rect radius 12 (MD3 Medium shape), fill #F3EDF7, shadow 0 1 2px.
Nav Bar: Rect H:80 fill #ECE6F0. Active pill: W:64 H:32 radius 16 fill #E8DEF8.
Chips: H:32 radius 8 border #CAC4D0. Selected: fill #E8DEF8.
FAB Extended: H:56 radius 16 fill #EADDFF.
6
Add MD3 Color Tokens to Assets
Press Alt+I → Assets → Colors → add:
#6750A4 md/primary
#EADDFF md/primary-container
#E8DEF8 md/secondary-container
#FFFBFE md/background
#F3EDF7 md/surface-container
#1C1B1F md/on-surface
#1B873C price/up
#C5221F price/down
7
Import the chart SVG directly
View source (Ctrl+U) → copy the <svg> chart block → save as chart.svg → drag directly into Penpot. It imports as fully editable paths — no tracing needed.
8
Set up prototype navigation
Click the Prototype tab (top right panel) → click the nav bar icon on each screen → drag the blue arrow connector to the target page frame. Press ▶ Play to preview the interactive flow. Share via the link icon for stakeholder review.
lightbulb
Material Design 3 spec applied in this template: Roboto type scale (Display → Label), MD3 shape scale (xs 4dp → xl 28dp), tonal surface color hierarchy (surface → surface-container → surface-container-highest), Navigation Bar with indicator pills (not tab bars), Filled/Tonal/Outlined button hierarchy, Filter chips for categorization, Extended FAB for primary actions, 8dp spacing grid, and MD3 baseline color scheme (Primary #6750A4).

Google's official MD3 Penpot kit: Search "Material 3 Design Kit" on the Penpot Community — there is an official kit you can duplicate and use with the component styles already built.
